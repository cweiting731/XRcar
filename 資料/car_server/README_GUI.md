# 小車 GUI 控制介面使用說明

## 安裝需求

在 Windows 上執行此程式前，需要先安裝 PyQt5：

```powershell
pip install PyQt5
```

## 執行方式

```powershell
python car_server_manual.py
```

或

```powershell
py -3 car_server_manual.py
```

## 功能說明

### 主要改變
- ✅ 移除了 Linux 搖桿控制（evdev）
- ✅ 改用 PyQt5 圖形介面
- ✅ 適用於 Windows 系統
- ✅ 保持相同的 UDP 通訊協定

### 控制介面

1. **方向按鈕控制**
   - `↑ 前進`: 油門設為最大 (255)
   - `↓ 後退`: 油門設為最小 (0)
   - `← 左轉`: 方向設為最左 (0)
   - `→ 右轉`: 方向設為最右 (255)
   - `◉ 停止`: 全部歸零 (128)

2. **精細控制滑桿**
   - **油門滑桿**: 可精確控制油門值 (0-255)
   - **方向滑桿**: 可精確控制方向值 (0-255)
   - 中心位置為 128（靜止/中立）

3. **按鈕操作**
   - 按住按鈕：持續動作
   - 放開按鈕：自動回到中立位置 (128)
   - 滑桿：即時調整，不會自動回中

### 狀態顯示

- 頂部顯示連線資訊：目標 IP、Port 和發送頻率
- 底部顯示當前狀態、油門值和方向值

### 通訊設定

預設設定：
- ESP IP: `192.168.0.154`
- ESP Port: `4000`
- 發送頻率: `15 Hz`

如需修改，請編輯檔案開頭的常數：
```python
ESP_IP   = "192.168.0.154"  # 修改為您的 ESP32 IP
ESP_PORT = 4000              # 修改為您的 ESP32 Port
SEND_HZ  = 15                # 修改發送頻率
```

### 關閉程式

關閉視窗時，程式會自動：
1. 發送中立指令 (th=128, hd=128)
2. 停止定時器
3. 關閉 UDP socket

## 技術細節

- 使用 QTimer 定時發送 UDP 封包
- 封包格式：`th={throttle},hd={inverted_handler}\n`
- handler 值會自動反轉：`256 - handler`
- 所有值範圍：0-255，中立值：128
